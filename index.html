lwPhylo

A lightweight, dependency-light JavaScript library for parsing Newick trees and plotting rectangular, radial, and unrooted phylogenies — built to hand straight to D3.

View on GitHub npm package Observable tutorial

What it does

One function turns a Newick string into an SVG tree. Everything else — layout math, tooltips, root→tip highlighting — is handled for you, but the lower-level layout functions are exported too if you want to drive D3 yourself.

Three layouts

Rectangular (cladogram/phylogram), radial (fan), and unrooted (equal-angle) — pick one with a single option.

Zero required dependencies

The parser and layout math have no dependencies at all. D3 is the only peer dependency, used purely for rendering.

Robust Newick parsing

Handles missing branch lengths, unlabeled internal nodes, polytomies, scientific notation, and missing trailing semicolons.

Interactive by default

Hover a tip to trace its root→tip path; pass highlightTips to pin specific paths permanently.

Tooltips out of the box

Every tip gets a formatted tooltip with its label and cumulative root→tip distance — customisable via tooltipFormatter.

Escape hatches

Need more control? readTree(), rectangleLayout(), radialLayout(), and unrooted() are all exported directly.

Quick start

Two ways to get a plot on the page: install from npm, or drop in the browser build via a script tag.

npm install @euphrasiologist/lwphylo d3

import drawPhylogeny from "@euphrasiologist/lwphylo/draw";

const newick = "((A:0.1,B:0.2):0.3,(C:0.15,D:0.1):0.2);";

document.getElementById("tree").appendChild(
  drawPhylogeny(newick, {
    layout: "radial",   // "rect" | "radial" | "unrooted"
    width: 500,
    height: 500,
    highlightTips: ["A", "D"]
  })
);
<script src="https://cdn.jsdelivr.net/npm/d3@7/dist/d3.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@euphrasiologist/lwphylo/dist/drawPhylogeny.umd.js"></script>

<div id="tree"></div>
<script>
  const newick = "((A:0.1,B:0.2):0.3,(C:0.15,D:0.1):0.2);";
  document.getElementById("tree").appendChild(
    lwPhyloPlot(newick, { layout: "rect", width: 500, height: 400 })
  );
</script>

Try it

Paste your own Newick string, or start from a preset. Renders live in your browser using this repo's own build — nothing is sent anywhere.
